# OneDrive 抽卡数据库同步

桌面端与 Android 端在 OneDrive 根目录下使用同一个共享数据库快照：

```text
Wuwa Gacha Tool/gacha-data.db
```

`gacha-data.db` 只包含抽卡记录、玩家导入状态和卡池历史边界。游戏目录、资源缓存、登录凭据及本机同步基线属于设备状态，不上传到 OneDrive；桌面端将数据库设备状态保存为 `app-state.db`。

## 同步规则

- 首次同步且云端为空时，将本机快照上传。
- 首次同步且本机为空时，校验并加载云端快照。
- 建立共同基线后，仅本机变化时上传，仅云端变化时下载。
- 本机和云端都从共同基线发生变化时停止同步，不执行最后写入覆盖。
- 上传使用 ETag 与 `If-Match`；云端在上传期间变化时停止并要求重新同步。
- 下载内容先经过大小限制、SQLite `integrity_check`、schema 版本和必要表校验，再在事务中替换共享表。
- 上传前从当前连接生成一致性快照，不上传 WAL 或 SHM 文件。

整库快照能准确同步删除、清空和模拟记录编辑，但不合并两端离线并发修改。同步期间应避免在另一台设备同时导入或编辑数据。

## 凭据

两端使用 Microsoft 公共客户端设备码登录，请求 `offline_access Files.ReadWrite`。桌面端刷新令牌保存在系统凭据库，Android 使用 Android Keystore 加密后保存；令牌、设备码和 Graph 响应不得写入日志。
