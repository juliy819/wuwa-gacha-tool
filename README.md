# Wuwa Gacha Tool

一款专为《鸣潮》玩家打造的本地抽卡记录管理工具，帮助你追踪唤取历史、统计保底进度、复盘 UP 池表现。所有数据仅保存在本机，不会上传到任何服务器。

版本 v0.1.0 · 作者 Juliy

![banner](docs/screenshots/banner.png)

---

## 核心特性

- **三种数据导入方式**：游戏目录自动读取、抽卡链接直连、本地 JSON 导入
- **多账号管理**：同一台电脑上多个角色记录独立保存，一键切换
- **保底进度追踪**：每个卡池独立累计垫抽，距 80 抽保底一目了然
- **UP 池表现复盘**：自动统计不歪率、歪/不歪次数、平均抽数
- **多视角记录浏览**：列表、宫格、表格三种视图自由切换
- **本地存储 + 删除前备份**：数据全程留在本机，清理操作前自动生成数据库备份
- **隐私安全**：不联网上报，不读取账号密码，仅解析本地日志与官方公开接口

## 界面导览

软件采用深色主题，顶部为自定义标题栏与导航，底部为状态栏，中间为三个主页面。

### 顶部导航栏

- 左侧显示软件标题与三个页签：**首页**、**记录**、**设置**，切换时有滑动指示动画
- 右侧依次为：
    - **玩家选择下拉框**（存在多个账号时显示），可快速切换当前查看的 UID
    - **刷新按钮**，重新读取本地设置、玩家列表与抽卡记录
    - **窗口控制按钮**（最小化 / 最大化 / 关闭）

整个标题栏可拖动移动窗口。

### 首页 · 抽卡概览

进入软件的第一站，集中展示当前账号的整体数据。

![home](docs/screenshots/home.png)

**数据导入（扫描抽卡）**

点击右上角「扫描抽卡」按钮，弹出扫描面板，提供三种方式：

| 方式      | 适用场景     | 操作说明                                                                |
|---------|----------|---------------------------------------------------------------------|
| 游戏目录    | 最常用，自动读取 | 填入或选择鸣潮安装目录（需含`Client\Saved\Logs\Client.log`）。工具会自动解码日志、提取抽卡链接并拉取记录 |
| 抽卡链接    | 手动粘贴链接   | 直接粘贴从游戏内抽卡历史记录页面获取的完整链接                                             |
| 导入 JSON | 迁移/备份恢复  | 选择本地 JSON 文件（格式需与游戏抽卡接口原始返回一致）                                      |

> 前置条件：使用「游戏目录」或「抽卡链接」前，请先在游戏内打开一次抽卡历史记录页面，以便日志写入链接信息。

**概览仪表盘**

- **六项核心指标卡片**：累计唤取、五星数量、五星概率、平均五星抽数、每个 UP 角色平均抽数、每把 UP 武器平均抽数
- **记录时间范围**：展示已导入记录的起止日期，并提示官方链接仅保留近约 6 个月
- **当前垫抽**：按卡池列出当前垫抽进度条与「距保底 X 抽」，达到 66 抽会高亮提醒
- **UP 角色池表现**：展示不歪率、不歪次数与歪的次数
- **最近五星**：展示最近 6 条五星记录，含角色名、所属卡池、抽数与是否歪

### 记录 · 唤取记录

完整的抽卡记录浏览与检索页面。

![detail.png](docs/screenshots/detail.png)

**左侧栏**

- 顶部显示累计唤取总数、五星数与歪的次数
- 卡池筛选列表：点击「全部卡池」或具体卡池进行筛选，每个卡池显示当前保底进度（如 `12/80`）

**主区域工具栏**

- **视图切换**：列表视图 / 宫格视图 / 表格视图
    - 列表视图：每条记录展示头像、名称、日期与保底进度条（按抽数变色：低绿、中黄、高红）
    - 宫格视图：卡片式布局，列数随窗口宽度自适应
    - 表格视图：完整表格，可在「五星记录」与「全部记录」之间切换
- **搜索框**：按名称、卡池名或日期模糊搜索
- **结果计数**：实时显示筛选后的记录条数

**分页栏**

- 列表/表格视图下可调整每页条数（25 / 50 / 100）
- 宫格视图按列数自动计算每页数量
- 支持上一页 / 下一页翻页

### 设置 · 管理目录与数据

**游戏目录**

- 输入或选择鸣潮安装目录，输入后会实时校验 `Client.log` 是否存在
- 校验通过后点击「保存目录」即可，后续扫描将自动使用该目录

**本地数据**

- 显示玩家数量与记录总数
- 按玩家列出每位的记录条数与时间范围，可单独删除某个 UID 的记录
- 「清空全部」可一键清空所有数据
- 所有删除操作执行前会自动创建完整数据库备份，并显示备份路径（可复制）

**删除确认对话框**

- 展示将删除的记录数量、涉及玩家数与时间范围
- 需手动输入对应 UID（或「清空全部数据」）确认后方可执行，避免误操作

### 底部状态栏

- 左侧显示软件版本号
- 右侧显示运行状态指示灯（就绪）

## 使用流程建议

1. 首次使用：进入「设置」填好游戏目录并保存
2. 在游戏内打开一次抽卡历史记录页面
3. 回到「首页」点击「扫描抽卡」，选择游戏目录方式开始扫描
4. 扫描完成后即可在首页查看概览，在记录页浏览明细
5. 多账号用户可通过右上角玩家选择下拉框切换查看
6. 建议至少每半年同步一次，避免官方链接过期导致较早记录丢失

---

## 数据与隐私

- 所有抽卡记录保存在本地数据库，不会上传到任何服务器
- 工具仅读取游戏目录下的 `Client.log` 用于提取抽卡链接，不涉及账号密码
- 抽卡数据通过官方公开接口获取，与游戏内一致
- 删除操作前会自动备份数据库，可随时恢复

---

## 注意事项

- 官方抽卡链接仅保留近约 6 个月历史记录，两次同步间隔超过 6 个月，较早记录可能丢失且无法自动补回
- 使用游戏目录扫描前，务必先在游戏内打开抽卡历史记录页面，否则日志中无链接信息
- JSON 导入格式需与游戏抽卡接口的原始返回一致（含 `uid` 字段与各卡池编号键）
